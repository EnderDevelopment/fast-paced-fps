# FastPacedFPS: Roblox First-Person Shooter Game

FastPacedFPS is a high-speed first-person shooter game for Roblox, designed to provide an adrenaline-pumping experience with fast-paced action, dynamic enemy AI, and responsive player controls. This project includes modules for player movement, enemy behavior, game management, and user interface, making it easy to create and customize your own fast-paced FPS game.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `PlayerModuleScript.lua` in the StarterPlayerScripts folder.
5. Place the `EnemyModuleScript.lua` in the ServerScriptService folder.
6. Place the `GameManagerScript.lua` in the ServerScriptService folder.
7. Place the `UIModuleScript.lua` in the StarterPlayerScripts folder.

## Use

1. **Player Movement**: The `PlayerModuleScript.lua` handles player movement and actions. Customize the `moveSpeed` and `jumpPower` variables to adjust player movement.
2. **Enemy Behavior**: The `EnemyModuleScript.lua` manages enemy behavior and interactions. Adjust the `enemySpeed` and `enemyHealth` variables to customize enemy characteristics.
3. **Game Management**: The `GameManagerScript.lua` controls the overall game state and logic. Modify the game state and events as needed.
4. **User Interface**: The `UIModuleScript.lua` manages user interface elements. Customize the UI elements to fit your game's needs.
